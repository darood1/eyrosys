Eurosys website

Upload the CONTENTS of this folder to the web root. Clean URLs are supported through page folders (for example /careers/index.html) and .nojekyll is included.

Important: the Careers and Quote forms are front-end forms only. Connect them to your chosen backend/form service before going live if you want submissions to be received.

Report pages for gender pay gap, carbon footprint and Planet Mark intentionally contain placeholders rather than invented figures. Replace these with verified organisational data before publication.
